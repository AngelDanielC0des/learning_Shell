0x01

HTML

Arquitectura: El esqueleto lógico que define la web semántica.

Dato 1: HTML es el lenguaje más paciente del mundo. Si cometes un error o no cierras una etiqueta, el navegador no explota. Dato 2: Devorador de espacios. Si pones 10 espacios en el código, HTML los ignora y solo muestra uno en pantalla. Dato 3: No distingue gritos. <BODY> y <body> funcionan igual, aunque por orden siempre se usan las minúsculas.
0x02

CSS

Diseño: Transforma ladrillos aburridos en una interfaz visual moderna.

Dato 1: La mentira de los círculos. En CSS los círculos no existen; son cuadrados con las esquinas tan redondeadas que engañan a tu ojo. Dato 2: La última palabra manda. Si das dos órdenes que se contradicen, CSS siempre obedecerá a la que esté escrita más abajo en el archivo. Dato 3: Herencia familiar. Órdenes como el color de texto se pasan de "padres" a "hijos" automáticamente para ahorrarte tener que repetir código.
0x03

JAVASCRIPT

Lógica: El sistema nervioso que reacciona a cada interacción del usuario.

Dato 1: Crisis de identidad. Aunque se llama JavaScript, su nombre oficial es ECMAScript. Dato 2: Dos tipos de nada. 'null' es un vacío que tú decides poner; 'undefined' es un vacío que aparece cuando no has asignado un valor a la variable. Dato 3: Tipado Dinámico (cambia de tipo), y Débil (mezcla tipos) y ASI (Automatic Semicolon Insertion): el navegador pone los ";" por ti si se te olvidan.
0x04

JAVA

Backend: Lenguaje robusto y seguro que orquesta la lógica desde el servidor y garantiza la comunicación íntegra con la base de datos.

Dato 1: Origen cafetero. Se iba a llamar 'Oak' (Roble), pero eligieron Java por el café de la isla de Java (Indonesia) que los programadores tomaban a todas horas. Dato 2: Tipado Fuerte y Estático. A diferencia de JS, aquí debes declarar qué es cada cosa (int, String) y no podrás cambiarlo después. Es pura disciplina. Dato 3: Filosofía WORA (Write Once, Run Anywhere). Gracias a su Máquina Virtual (JVM), el código que escribes en Windows funciona en un cohete o una tostadora sin cambios.
0x05

SQL

Datos: Archiveros inteligentes que guardan y relacionan toda la información.

Dato 1: No es programación, es una petición (Query). En otros lenguajes explicas el CÓMO; en SQL solo pides el QUÉ (SELECT). Dato 2: No distingue gritos. SELECT es igual que select, pero usamos mayúsculas por convención para diferenciar las órdenes de los nombres de tus tablas y columnas. Dato 3: Reglas de oro (ACID). Son 4 normas que garantizan que si hay un apagón en una transferencia bancaria, el dinero no se pierda: o se hace TODO o no se hace NADA. (Atomicity.Consistency.Isolation.Durability.)
